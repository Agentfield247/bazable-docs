# Introduction

Bazable is a Git‑native API contract management CLI.  
It scans your frontend code, builds an API contract automatically, and enforces it across your team.

## Key Features
- Zero‑config API extraction from any language
- Real‑time contract enforcement (dead URLs, payload mismatches, over‑fetching)
- Cloud sync with device‑code authentication
- Mock server, TypeScript generation, and backend scaffolding
- AI‑ready (JSON output, MCP server planned)
